# حالة فجوات موديول المرتبات

## منفذ
- نماذج الموظف والعقود وملف المرتبات.
- بنية البنود ومصادر البيانات واللقطات.
- نماذج المعادلات والسياسات.
- محركات ضريبة/تأمين/Gross-up أولية.
- دورة المرتبات والنتائج والصرف idempotent.
- صفحات Blazor أولية وصلاحيات أساسية.

## غير مكتمل
- CRUD كامل للبنود وإصداراتها ومصادر البيانات.
- محرر معادلات فعلي وتقييم AST آمن.
- حل السياسات والأولويات والاستثناءات.
- Orchestrator يحسب مرتب الموظف من العقد والبنود والمتغيرات.
- ربط الحضور والإجازات والتسويات والقروض بالحساب.
- شاشة دورة كاملة للحساب والمراجعة والاعتماد والصرف.
- الترحيل المحاسبي الفعلي وتقارير مفردات المرتب.
- استيراد تاريخي فعلي واختبارات PostgreSQL والأداء.
